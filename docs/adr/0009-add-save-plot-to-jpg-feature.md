# 9. 新增將圖表儲存為 JPG 檔案的功能

- **日期**: 2026-03-16
- **狀態**: 已接受並實施

## 背景 (Context)

使用者需要一個快速、直觀的方式來匯出目前在「實時 IV 曲線戰情室」(`IVMonitorWindow`) 和「長期穩定性與壽命分析中心」(`TrendChartWindow`) 中顯示的圖表，以便於報告撰寫、數據分享或線下分析。

目前軟體缺乏內建的圖表匯出功能，使用者若想保存圖表，只能依賴作業系統的螢幕截圖工具，這不僅效率低下，而且無法保證圖片的品質與範圍的精確性。

## 決策 (Decision)

我們決定在這兩個核心的圖表視窗中，各自新增一個「儲存圖表 (JPG)」按鈕，提供一個無縫的、內建的匯出功能。

具體實施步驟如下：

1.  **技術選型**:
    -   利用 `pyqtgraph` 函式庫內建的 `pyqtgraph.exporters.ImageExporter` 模組來執行實際的圖片渲染與儲存。此工具能確保匯出的圖片與螢幕上所見的圖表內容（包含縮放狀態）完全一致。
    -   使用 `PyQt6.QtWidgets.QFileDialog` 來提供一個標準的、符合作業系統風格的「另存新檔」對話框。

2.  **修改 `gui/trend_chart_window.py`**:
    -   **UI**: 在左側的控制面板底部新增一個「儲存圖表 (JPG)」按鈕 (`QPushButton`)。
    -   **邏輯**:
        -   為此按鈕連接一個 `_on_save_plot_clicked` 處理函式。
        -   此函式會觸發 `QFileDialog`，讓使用者選擇儲存路徑和檔名，並提供一個包含當前時間戳的預設檔名 (例如 `Trend_Chart_20260316_143005.jpg`)。
        -   確認後，呼叫 `ImageExporter` 將 `TrendPlotWidget` 的內容匯出為 JPG。
        -   透過 `QMessageBox` 向使用者回報儲存成功或失敗的訊息。

3.  **修改 `gui/iv_monitor_window.py`**:
    -   **UI**: 在右側的資訊面板底部新增一個「儲存圖表 (JPG)」按鈕。
    -   **邏輯**:
        -   與上述邏輯類似，同樣建立 `_on_save_plot_clicked` 處理函式。
        -   為了方便辨識，其預設檔名會包含更多上下文資訊，例如通道號和設備名稱 (`IV_Curve_CH08_Device_A_20260316_143210.jpg`)。
        -   匯出對象為 `IVPlotWidget` 的內容。

## 影響 (Consequences)

### 正面影響
- **功能完整性**: 提供了一個使用者高度期待的內建功能，補全了數據可視化後的「產出」環節。
- **提升工作效率**: 使用者不再需要使用外部工具進行截圖，可以直接在軟體內完成高品質的圖表匯出，簡化了工作流程。
- **使用者體驗改善**: 新增的按鈕位置直觀，操作流程（點擊 -> 選擇路徑 -> 儲存）符合使用者預期，並提供明確的成功/失敗回饋。

### 負面影響
- 無明顯負面影響。此功能為現有介面的擴充，不影響原有核心量測邏輯，且實作上與現有技術框架完全相容。
