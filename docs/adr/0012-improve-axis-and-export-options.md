# 12. 優化圖表 X 軸顯示與擴充圖片匯出選項

- **日期**: 2026-03-18
- **狀態**: 已接受並實施

## 背景 (Context)

使用者提出了兩項關於圖表視窗的使用者體驗優化建議：

1.  **`TrendChartWindow` 的 X 軸不夠智慧**:
    -   當 X 軸為「量測序號」時，刻度會顯示為浮點數 (如 "2.0") 而非整數。
    -   當 X 軸為「運行時間」時，單位被固定為「小時」，導致在實驗初期時間跨度很小時，會出現如 "0.001 hours" 這樣不直觀的標籤。

2.  **圖片匯出格式單一**:
    -   `TrendChartWindow` 和 `IVMonitorWindow` 的「儲存圖表」功能都只支援 JPG 格式，無法滿足使用者對無損圖片 (如 PNG) 或其他格式的需求。

## 決策 (Decision)

我們決定採納使用者的建議，對這兩項功能進行優化，以提升圖表的專業性和軟體的易用性。

### 1. X 軸智慧調整 (`TrendChartWindow`)

-   **修改 `update_chart` 核心邏輯**:
    -   **智慧時間單位**: 在繪製圖表前，程式會先計算所有數據點的總時間跨度。
        -   若總時長 < 2 分鐘，X 軸單位自動設為「秒 (Seconds)」，除數為 1。
        -   若總時長 < 2 小時，X 軸單位自動設為「分鐘 (Minutes)」，除數為 60。
        -   否則，單位維持「小時 (Hours)」，除數為 3600。
    -   **T80 單位校正**: 在計算 T80 壽命時，無論當前 X 軸顯示何種單位，其標籤中的 T80 結果都會被標準化，統一以「小時 (h)」為單位顯示，以確保一致性。
    -   **整數刻度**: 對於「量測序號」模式，透過設定 `axis.enableAutoSIPrefix(False)` 來禁用科學記數法，這有助於 `pyqtgraph` 在數據為整數時優先選擇整數刻度標籤。
-   **修改 `_get_x_axis_values`**:
    -   此方法被重構，增加了一個 `divisor` 參數，使其能根據 `update_chart` 傳入的除數來計算時間軸的數值。

### 2. 擴充圖片匯出格式 (雙視窗通用)

-   **修改 `_on_save_plot_clicked`**:
    -   在 `TrendChartWindow` 和 `IVMonitorWindow` 中，都修改了此方法。
    -   將 `QFileDialog.getSaveFileName` 的 `filter` 參數從僅支援 JPG 擴充為一個包含多種常用圖片格式的字串：`"PNG 圖片 (*.png);;JPEG 圖片 (*.jpg);;TIFF 圖片 (*.tif);;BMP 圖片 (*.bmp);;所有檔案 (*)"`。
    -   將預設儲存格式從 `.jpg` 改為 `.png`，因為 PNG 是無損格式，更適合科學圖表的儲存。
-   **修改按鈕文字**:
    -   將兩個視窗中的按鈕文字從「儲存圖表 (JPG)」改為更通用的「儲存圖表...」，以反映其支援多格式的能力。

## 影響 (Consequences)

### 正面影響
- **圖表可讀性提升**: `TrendChartWindow` 的 X 軸現在能根據數據內容顯示最合適的單位，讓使用者能更直觀地理解時間尺度。
- **功能專業性提升**: X 軸刻度的格式（整數 vs 浮點數）更符合數據本身的性質。
- **功能靈活性提升**: 使用者現在可以根據自己的需求（如報告、論文、簡報）選擇最合適的圖片格式進行匯出，極大地增強了軟體的實用性。

### 負面影響
- 無。本次修改是對現有功能的增強和優化，未引入任何複雜性或風險。
